# Security Policy

Ryutility is a static Jekyll site. All calculations run locally in the user's browser; there are no user accounts, databases, or server-side APIs.

## Reporting a Vulnerability
If you discover a security issue (such as an XSS vector in URL query parsing or a dependency vulnerability), please do **not** open a public issue with exploit details.

Instead, report it privately via https://ryutility.com/contact/ with steps to reproduce. We will review and address confirmed issues promptly.
