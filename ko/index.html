무료 러닝 계산기

{% include page-updated.html %}

페이스, VDOT 훈련 존, 심박수, 기록 예측, 스플릿, 트레드밀·더위 보정 — 로그인 없이 바로 계산합니다.

Ryutility는 숫자를 바탕으로 훈련하는 러너를 위한 계산기 모음입니다. VDOT 훈련 존, 카르보넨 심박수 존, 목표 페이스, 레이스 기록 예측, 구간 스플릿, 트레드밀·기온 보정까지 모두 검증된 공식에 기반해 브라우저 안에서 즉시 계산합니다.

수치 계산 방식

모든 계산기는 사용자 기기의 브라우저에서 직접 실행되며, 입력값과 계산 공식의 출처를 각 페이지 하단에 명시합니다. 훈련 존은 Jack Daniels의 VDOT, 레이스 예측은 Pete Riegel(1981)의 1.06 지수 공식, 심박수 존은 Karvonen 예비심박수 방식과 Tanaka 등(2001)의 최대심박수 추정식("220 - 나이" 대신)을 사용합니다. 트레드밀 경사도 보정은 ACSM 러닝 방정식을 따릅니다. 자세한 출처와 한계는 소개 페이지에서 확인할 수 있습니다.
